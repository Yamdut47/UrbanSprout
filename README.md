# 🌱 UrbanSprout

A responsive gardening e-commerce website designed for urban gardeners who want to grow plants in small spaces such as balconies, rooftops, and windowsills.

## 🔗 Live Demo

https://urbansprout.netlify.app/

---

## 📖 About The Project

UrbanSprout is a front-end web development project created as part of an academic coursework assignment.

The website provides an engaging online platform where users can:

- Browse gardening products
- View product discounts
- Read informative gardening blogs
- Explore research and comparison studies
- Learn about the project creator
- Experience interactive JavaScript functionality

The project focuses on modern UI design, responsive layouts, semantic HTML structure, CSS styling, and JavaScript interactivity.
